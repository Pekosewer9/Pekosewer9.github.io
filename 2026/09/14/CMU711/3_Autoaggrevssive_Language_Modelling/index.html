Autoaggresive Language Modelling

Types of prediction:

  • Binary
  • Multi-class
  • Structered - Exponential/infinate labels (maybe like translatations,sequence prediction)

Language Modelling

language model is a probability distribution over all sequences

P(X)

Conditional generation:

x_t+1:T(output) = P(X_t+1:T(output) | X_1:t(input))

Auto-regressive Language Models

P(X) = multi(p(x_t | x_1, … x_t-1)) t = 1->T

用马尔可夫链来预测next token

Bigram models

Each token is determined by the previous one token

  1. split the dataset into training,valid,test
  2. compute the probability distribution: p(x_t|x_t-1) = count(x_t-1, x_t) | Σt’ count(x_t-1,x_t’) -> maximum likelihood(最大似然)
  3. minDkl = min{ -p*(x)logp/p*(x) } 用P去接近P*（P_Data）数量的散度
    最后的结果是argmin {-1/D(data集大小) Σ（logp(x)}
    max{Σx log(x)} -> 操控参数来让让logp(x)最大化

Using log space
用log 防止概率太小而产生下溢或者数值不稳定

Evaluation

  1. Log-likelihood - use test datasest
    NLL = -Σlog(p_t | p_<t)

  2. Per-token average NLL
    上面的NLL / Ttotal

  3. Perplexity
    exp(Average_NLL)

perplexity -> 接近1 -> 预测成功
perplexity -> 接近num_class -> 平均预测

Training Ngram Models

  1. 有可能矩阵非常稀疏,有些甚至为0
    -> 加上’fake count’ 去防止0的出现

  1. simliarity and intervening words
    -> neural network

  2. Long-distances dependencies(长上下文)
    -> Transformer

现在的LLM仍然基于Autoaggressive的马尔可夫预测，但是引入了思维链，赋予了模型在推理时间的动态分配计算资源的能力，有些最新的架构用MTP模块同时预测未来的多个token

when to use n-gram models

  • n-gram models查询速度快
  • 可用于快速过滤数据等

Neural Language Model

  • use learned, distributed representation

把Nwords的feature combined了

我们只是把language 任务变成了 classfication 任务

similar context create similar hidden state

similar input create similar embeddings

    valid data to tune hyperparameters, perform ablations

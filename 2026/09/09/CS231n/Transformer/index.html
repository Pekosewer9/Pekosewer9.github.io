ATTENTION

Seq2Seq with RNN

A ENCODER ht = fW(x_t,h_t-1) RNN
ENCODER will summarize the all the context as C( Last hidden state )

A DECODER A DIFFERENT RNN
有一个Initial decoder state s0

s_t = Gu(y_t-1, s_t-1, c)

问题: 获取上下文的唯一向量只有一个C， 维度也固定
想法: 给予Decoder回看Encoder模型的方法

  1. initial state s0
  2. 计算s0和前面 Encoder 不同隐藏状态的对齐得分(Alignment scores)， 这个得分e_t_i是一个标量
  3. softmax函数来 让对齐得分同一个s_t 对不同的h_i 归一化
  4. 把之前的信息按照重要度汇总，变成 c_t = sigma(a_t_i * hi)
  5. Deocder: s_T = Gu(y_t1, s_t1, c_t)

how to initialize state s0

ATTENTION 不只可以用在RNN上， 还有一个更加普遍的机制

  • Query Vector(s) - Q
  • Data Vector(h) - K
  • output Vector© - V

  1. 计算相似性函数 - 用点积 / sqrt.np(D_q)
    D_q 是 Query的维度， 让最后结果的方差仍然是1, 不然softmax会太过极端， softmax两头导数都是接近0

  2. 并行处理一组查询
    Q[N_Q X D_Q] ,
    X[N_X X D_Q]

    E = Q * X^T / sqrt(D_Q)
    -> E = [N,Q , D_Q , N_X]

  3. softmax对每一行执行

  4. A = softmax(E,dim = 1) = [N_Q , N_X]

  5. Y = AX -> 线性组合

key_matrix : W_k = [D_x , D_Q]
query_matrix : Q = [N_Q , D_Q]
value_matrix : W_v = [D_x , D_V]

K和V是两个不同的过滤X中信息的方式， 一个是注重于信息，一个是注重于计算相似度

K = X · W_k -> 查询相似度
V = X · W_v -> 获取每个X能从上下文提取的的信息

  • self-attention Query 和 X 是一样的 , 适用于输入是同一格式的情况
    我们会将每一个输入的 X 都转化为 Q K V

Q = XQ K = XK
V = X`V

在硬件上， 执行大的矩阵乘法会比执行多次小的省时间
所以我们很常见就是把W_Q , W_K , W_V拼接起来一起点积X

自注意层的置换不变性（在推理层面） -> 自注意层本身对输入的位置无所谓， 输入相同的东西在不同位置也是一样的

解决， 位置编码， 在输入X加入向量层表示token的索引

掩蔽式注意力机制（masked attention）

让K 和 X计算出来有些位置是 -无穷大， 这样softmax有些位置就是0

应用：语言输入（不让语言看到后面的内容）

multi-head attention

将X路由到不同的self-attention-layer上 ， 用不同的Q K V，把输出的Y堆叠起来， 在输出的时候进行维度投影 -> O

现在的self-attention几乎都是多头的

但是也可以用一个矩阵乘法来进行

所以attention推理基本上就是4个矩阵乘法

矩阵乘法highly - effienct, parallable

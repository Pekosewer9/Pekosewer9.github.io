4.Recurrent Neural Networks

Context

  • 因为马尔可夫链，理论上，我们可以让上下文无限长
  • 但是很容易遇到梯度消失问题

Sequence modelling

  1. Recurrence -> RNN
  2. Convolution -> CNN
  3. Attention -> Transformer

Standard RNN

Example: Language modeling -> BPTT

total loss = Σloss

问题

  1. 难以并行化，计算之间有依赖关系

RNN的推理时间复杂度是O(N)

Vanishing Gradient

容易梯度爆炸或者梯度消失，取决于|W|

Solutions

  1. Gating function(门控)
    我们会有一个可学习的标量z_t
    ht = (1 - z_t) * h_t - 1 + z_t * ~h_t(这个~h_t是之前算出来的)
  • 若z_t = 0, 那么就是RNN
  • 若z_t = 1 ,那么就是记住很之前的东西，达到长距离依赖

  1. 残差
    h_t = h_t-1 + ~h_t

  2. GRU(Gated Recurrent Unit)
    有两个门，一个是update gate， 另一个是 reset gate（给出了有一个擦除）

先重置门r_t * h_t-1 ，再让更新们决定最后的隐藏状态，r_t,z_t都是长度为(hidden_state,)的向量

  1. LSTM

Encoder-Decoder

如果让Decoder和Encoder都成为RNN，问题是如何链接

  • 把decoder的初始隐藏层变成Encoder的最后一层隐藏层的变换或者直接相等

  • 同样的将Encoder和Decoder一起训练， 由于Encoder没有输出， 所以让Decoder的每层输出都softmax

Attention

我们会看每一个hidden state
current_hidden state - Query
an = score(Q,h_n) normalization
output = Σa_n * h_n

Pretrain

是base model 训练的第一步

  • 目的
  1. 用更少的数据来进行
  2. 在相同的数据的情况下， 获得更好的表现
  3. 一个模型可以应用于不同的任务

Pretrained_models:

BERT, GPT-3, Llama, Deepseek-v3

我们如何评判这些Pretrained model

  1. 架构
  • (pre-norm vs post-norm) (分组查询query)
  1. 任务
  2. 预训练使用的Data
  3. hyperparameters -> e.g. learning_rate batch_size

Pre-training task

两个主要的Pre_training 任务

Masked Language Modelling(不是next-token predictions)

  1. randomly mask the token
  2. predict the token

Example: BERT

  • DATA:Wikipedia, BooksCorpus

随机选择15%tokens， 在这些些token中， 80%被MASK， 10%被用随机的token替换这些token,10%不变

10%随机token可以让模型对提供的数据更有审视性

BERT不擅长generate文本,但我们可以finetuning

FineTuning Example:

Fine-tune the weights (either just W, or all weights). Example:

Data: (movie review, {positive, neutral, negative})

Initialize the model with BERT

Minimize cross-entropy loss with gradient-based optimization

我们只取BERT模型最后的hidden layer,用来当作这句话经过Transformer的represent

由于BERT的TransFormer是双向的， 所以每一个Ti都包含全部的上下文信息，我们取开头的[CLS] 字符的Hidden layer来进行表征

Autoregressive language modeling(就是训练目的是预测下一个词的modelling)

Maximum Likeihood -> learn to compress

  • 我们有一些data distribution， 我们的目标是压缩它
  • 我们要寻找binary code{0，1}的序列去表示这个分布

Arithmetic coding（算术编码）

我们可以将整个输入的数据序列映射为(0,1)之间的一个[a,b) 区间， 最终用这个区间内的一个二进制小数来代表整段数据

Example: GPT-2， Llama

How-can model do zero-shot data

模型已经学习到了下游的任务

规律：随着喂给模型的数据和模型的参数量变大，出现收益递减的趋势
参数量大的模型Loss降得更快， 高维空间中有更少的鞍点与局部极小值阻碍 ， 所以梯度下降更高效， 而且有更好的拟合能力， 所以LOSS下降快
会有training spike 可能原因：梯度裁剪， 数据集切换， 刚好到被污染的数据集， 中间经历了checkpoint恢复，FP16等的overflow

Evaluate the pre-training

  1. Loss(Training,validation,test)

  2. few-shot prompting -> Few-Shot Prompting
    （少样本提示） 是使用大语言模型（LLM）时的一种提示工程（Prompt Engineering）技巧。
    它的核心做法是：在发送给模型的 Prompt（提示词）中，显式地提供少量（通常是 1 到 5 个）“输入-输出”的示例（Exemplars），以此来“示范”并引导模型按照你期望的格式、逻辑或风格来完成当前任务。

  3. Fine-tuning

“Fuzzy strategy: minhash” 指的是在数据去重或相似性搜索中，利用 MinHash 算法来实现模糊匹配（Fuzzy Matching） 的一种策略。
简单来说，它的核心思路是：不要求两条数据完全一模一样，而是通过 MinHash 快速找出那些“高度相似”的数据。

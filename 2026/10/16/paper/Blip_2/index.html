BLIP-2

Created2026-10-16|Updated2026-10-16
|Post Views:
  • Q：BLIP-1中的ITC的文本编码器是预训练过的这我知道， 我的问题是BLIP1中的ITM,LM架构比起原来的文本Transformer多了Cross-Attention层，这是否意味着这两个是从头开始训练的

Ans:不是的， cross-attention随即初始权重，其它层都是可以和自回归LLM的参数继承的

  • 问题:这样子预训练会应用于到所有LLM层，规模太大了

  • 解决：在VLP期间保持现成的预训练模型冻结(图像编码器/文本编码器)

BLIP-2框架概述。我们采用两阶段策略预训练一个轻量级查询Transformer，以弥合模态差异。第一阶段从冻结的图像编码器中引导视觉-语言表征学习。第二阶段从冻结的LLM中引导视觉-语言生成学习，从而实现零样本指导的图像到文本生成

第一段是视觉-语言表征，类似于BLIP的ITM

第二段是视觉-语言生成，类似于LM

我们已经知道了LLM的泛化能力，我们可以冻结LLM的

  • 在端到端的VLQ的中， 我们有几个很好的目标:1.图像文本对比。 2.图像文本匹配 3.掩码语言建模(分别对应ITC,ITM,LM)

Q-Former

左边Transformer的输入是32个可学习的768维度queries参数，经过层层self-attention，cross-attention学习image Encoder输出的表征， 提取出视觉

右边是一个文本transformer,和self-attention共享参数

图像 → 冻结的 ViT → 图像特征 ─────────────┐
↓ Cross-Attention
可学习的 Query → [Q-Former 多层处理] → 更新后的 Query
↕ Self-Attention
文本 token → [同一套 Q-Former 层] → 文本表示

共享self-attention和FFN -> 对其能力

相当于query和text是在同一队列里面进入的，只不过query是经过cross-attention通路， text没有 ，text它们两个可以互相注意也可以进行注意力mask

  • 我们联合优化了三个预训练目标

第一阶段

  1. ITC预训练
    图片这一路：ViT 把图片切成许多视觉特征。32 个可学习 Query 进入 Q-Former；在 Cross-Attention 层里，Query 读取 ViT 的图像特征，逐层形成带有图像信息的表示。最后每个 Query 输出一个向量，再经过投影层并归一化。得到 32 个图像向量。ViT 冻结，Query 和 Q-Former 可训练。

文本这一路：句子被切成 token，例如 [CLS], a, cat, wearing, sunglasses, [SEP]。文本 token 进入同一 Q-Former 的文本路径。每一层的 Self-Attention 中，每个有效 token 都可以读取句子里其他有效 token；Padding 位会被屏蔽。经过多层后取 [CLS] 的输出，经过文本投影层并归一化，得到 一个文本向量。

  1. ITG预训练:
    因为要生成文本，所以要先由query提取， 再通过自注意层传递给文本token，每个文本token可以关注所有查询及其之前的文本token

我们将[CLS]标记替换为新的[DEC]标记,[DEC] 标记只能看到左侧已经提炼好的图像 Query,作为第一个标记指示解码任务

  1. ITM预训练

这是一个二元分类任务，模型需要预测图像-文本对是正例（匹配）还是负例（不匹配）。我们使用双向自注意力掩码，其中所有查询和文本都可以相互关注。输出查询嵌入从而捕获多模态信息。我们将每个输出查询嵌入输入到一个二分类线性分类器中以获得logit值

第二阶段

我们把32个Quries看图后经过Transformer的32个视觉向量(如果维度不对还要经过一个全连接层， 比如LLM隐藏层维度可能是4096， 那就需要768 * 4096的FFN)输入一个LLM模型(如OPT或者FLAN-T5)，这个大语言模型，基本就相当于差不多等于prompt enigneering里面的先注入， 就相当于先把前置的知识token输入，再输入问题

训练

模型预训练： 和BLIP一样的数据， 加上CapFilt方法合成的数据，我们用BLIP的方法生成是个标题， 并基于CLIP的文本相似度去取排名前两位的训练数据，并在每个预训练步骤中随机抽取一个标题

预训练的视觉大模型:ViT-L/14,ViT-g/14

实验

BLIP-2依托了强大的LLM的原始权重，在零样本任务中表现特别好

我们只需要改变文本提示， 就可以很轻易地控制图像到文本的生成

局限

预先提供几组图片-文本对的样例后ICL的能力并没有提升， 可能是由于训练集的基本都是但对的图像-文本对， 没有多组或者多对一的数据

  • Q：那些参数更新了
    哪些参数会训练？
    Q-Former 本身：Query 参数、Transformer 中的注意力层和 FFNCross-Attention，以及相应的投影层和任务输出层。Q-Former 从 BERT 权重初始化，所以它是从随机参数开始；训练会继续调整这些已有权重，并学习新增的跨注意力部分。第一阶段的 ViT 图像编码器冻结；外部的大语言模型还没有接入。Q-Former 约有 188M 参数

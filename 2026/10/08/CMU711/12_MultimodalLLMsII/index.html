Generative modeling paradigms(范式)

  1. Autoaggressive
    generate one dimension(pixel/token) at a time given previous ones

  2. VAE
    Encoder -> Lantent Space -> Decoder

  3. GAN
    X+ X- -> Discriminator -> 0/1 -> lantent space -> Generator -> x

  4. Diffusion model
    Gradually add noise to an image then learn to denoise

Auto-regressive

[Image GPT]

Challenge:

  1. sequence length (h * w * channel) [Long content length]
  2. each pixel tokens carries little semantic information compared to a word token(a lot of data needed)

VQ-VAE(Vector Quantity VAE)

Learn to reconstruct the image by compressing it into a vector and uncompressing it

  • 我们想要中间的lantent space 接近标准高斯分布
    如果没有高斯分布约束，普通的自编码器（VAE）会将不同的类或特征孤立地映射为高维空间中的某些“离散孤岛”。
    连续性（Continuity）：通过加入高斯分布假设（搭配重参数化技巧中的噪声采样），相当于给潜在向量注入了微小扰动。这迫使 Decoder 保证：潜空间里两个相邻的点，解码出来的图像也必须相似。

平滑插值（Interpolation）：高斯分布是一个平滑的凸集空间。在两个样本点 $\mathbf{z}_1$ 和 $\mathbf{z}_2$ 之间做线性插值，中间经过的区域依然是大概率的高斯高密度区，解码出来的图像变化会非常平滑自然（例如从“笑脸”渐变为“哭脸”），不会在半路解码出毫无意义的噪点。

  • Reconstruction Steps
  1. Sample a lantent variable z
  2. turn into x with a decoder
  3. encoder maps data x into a lantent variable y
  4. 计算z条件下x的可能性， 最小化

训练Loss = Reconstruction loss(重建后的相似度) + Regularization(高斯分布)

这里的p(z|x)是让给定图片x后输出的分布符合高斯分布-> 因为映射到lantent space其实是一个分布而不是一个值

  • 问题：Sampling这个过程是不可微的
  • 我们用reparameterization
    我们用一个高斯分布中的取值来进行采样
VAE Evidence Lower Bound

我们在latent space中插值可以得到manifold

  • 我们用tokenizer 生成一组离散的数字， 这样子我们就能通过语言模型预测了
    怎么通过可微的方式来生成这一组离散数字呢
    用Codebook Vector, 用最近的邻居的算法来进行
    前向传播的时候， zq = ek ， 反向传播的时候， 假装量化这一步是恒等函数
    Loss中要让codebook 的 vector 接近Encoder输出的ze -> 这一步要更新codebook embedding
    还要让Encoder z 接近codebook vector, 更新Encoder

    当我们把图片quant的离散数字展平， 我们就能送入Transformer做预测下一个discrete token
  2. discrimination

我们把生成的图片当反面， 原来的图片当正面，训练我们的Discriminator

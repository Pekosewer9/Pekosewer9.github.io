Text, Image -> Text


Vision Architecture Basic -> ViT(Use Transformer)

Learning image representation -> CLIP

Combining with LLM -> Llava


ViT


    

  1. 将图片分为块(patches)
    2. 

  2. 把每个块展平成为vector(记住要加贺上position embedding)
    3. 

  3. use stantard transformer
    4. 




    

  • 

    对每一个patch 我们用一个W(P * P * C) * (D)的矩阵线性投影成一个embedding + position embedding
    

    • 

  • 

    position embedding 可以用Rope ， 研究表明模型会自动学习空间位置
    

    • 



训练


    

  1. 在序列头部加上一个可学习的[CLS] 向量
    2. 

  2. 在transformer尾部加一个FFN投影到类别分类
    3. 

  3. 用这个[CLS]变量输出的类别进行交叉熵， 来梯度下降
    4. 



提取自 ViT 模型最第一层 Patch Projection 矩阵（通常记作 $\mathbf{E}$ 或 $\mathbf{W}_e$）：是把图片投影成embedding再送入transformer之前

类似于第一层卷积核



学习到的position embedding也是有很强的范式



[CLS]的注意力矩阵的地方



CLIP(学习如何表示图片)


    

  • representation也可以叫做latent space
    • 



我们不想image 只用来预测class label

我们可以用textual description image提供来提供更多信息


    

  1. 我们用两个encoder(ViT Transformer, Transformer)
    2. 

  2. 两个encoder分别把图片和对应的描述文字给映射成向量
    3. 

  3. 我们通过训练让配对的向量更近， 不配对的向量远离彼此
    4. 



训练


    

  1. 用点积判断相关度， 我们想要升级对角线上的相关度， 降低非对角线的相关度
    2. 



    

  • Loss Function
    • 




CLIP的用法


    

  1. zero-shot classifier
    2. 




Llava(VLM)


    

  1. 每个patch都能经过输出一个视觉token(不包括[CLS])
    2. 

  2. 通过投影层将视觉token的维度对齐到大语言模型的embedding 维度
    3. 

  3. 将视觉token和文本token沿维度拼接成一个统一的维度序列
    4. 



实际上就是把图片patch看成前置的信息， 和文本的tokenizer后的embedding一起被送入transforemer,进行预测下一个词的训练过程中


[PaliGemma, SigLIP]


    

  • 结论:最好的效果是同时更新ViT和语言模型
    • 



    

  • 我们可以移掉image encoder吗，直接传入raw patches吗
    
目前不行

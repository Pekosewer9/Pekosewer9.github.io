在训练过程中， 最大似然只能告诉我们提高事件发生的概率， 而强化学习能让我们减少某些事情发生的概率

Reinforcement learning

我们在执行特定的任务的时候可以用一个reward函数优化

basic-RL:

method:MDP,马尔可夫决策链
E(s_t+1|s_t,a_t): environment transictions

R(s_T,a_T): reward function

A(a_t|s_t): take actions

trajectory = {s0,a0,r1,s1,a1,r2……}

return : total reward for the episode

Observations(智能体实际上能看到的): Ot = O(s_t)

text generations

  • agents : LLM
  • observations: sequence generated so far
  • Actions: generate next token
  • Rewards: the final answer correct

Example: math problem solving

Types of RL algorithms

  1. Policy based methods
    直接学习policy
  2. value based methods
    知道a_t和总value的预测关系，从而制定policy
  3. model based methods

Policy gradient methods

  • Q1: Policy函数中 ，我们需要从概率分布中采样一个动作a_t,动作概率本身是离散的，这个过程本身不能求普通导数
  • Q2：Reward往往不是一个可微的函数，我们执行完A后最终获得奖励是+1/-1，这个本身就是无法求导的

Score Function Gradient Estimator
-> 转化为可微的函数

我们可以用multi-samples来估计下面这个值， 因为已经化成期望的形式了， 所以就可以中心极限定理

f(x)也就是奖励函数本身之和state有关， 和x无关，所以R_t可以放在外面变成这个形式

所以R_t ， 高的时候， 会push up the probability of policy(at|s_t)的概率

如果R_t 为负数就会很鲜明地惩罚

  • Q:这个不还是奖励出现频率高的吗， 是因为Reward会有负数才会惩罚吗， 如果reward全部正数是不是就和最大似然差不多？
    不一样的是， 每个样本出现后都会有一个值， 这个值会决定梯度的大小权重，我们就可以制定让它往哪里走的策略，对样本的利用率更大

训练过程:

  1. collect tragectories
  2. compute returns
  3. policy gradient loss:
  4. update the policy

vanilla

better
1.Re-weight the gradients
2.control step size(不要在改变好的时候突然改变很大的策略)

Discounting(Credit assignment)

discounted the final reward by how far it is in the future

Baseline

我们考虑每一回合的预期的得到的奖励

我们可以学习value-based function去知道预期奖励

Adavantages

v是这个state的预期value

Large updates

  • PPO : 不要让policy一次移动的太远了

ratio表示了update后的policy概率和原来的偏离程度， 等于1是没有偏离

如果太大了，我们会clip掉ratioA(x,y)，防止太大的update,往好的A(x,y)方向偏移的我们就会让它更好
